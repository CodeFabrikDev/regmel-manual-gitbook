# Adicionar intervenções

Para adicionar as intervenções que serão realizadas, primeiro o promotor deverá realizar a vistoria em:

{% content-ref url="cadastrar-vistoria.md" %}
[cadastrar-vistoria.md](cadastrar-vistoria.md)
{% endcontent-ref %}

Para adicionar intervenções, acesse a tela inicial&#x20;

Clique em `Projetos de Melhoria`

<figure><img src="../.gitbook/assets/image (23).png" alt="" width="213"><figcaption></figcaption></figure>

Na página exibida, selecione um item com o status 'Aguardando Melhoria' na lista de vistorias

Clique em `Adicionar intervenções`

<figure><img src="../.gitbook/assets/image (24).png" alt="" width="212"><figcaption></figcaption></figure>

Na página exibida, preencha os dados solicitados pelo sistema

* Cômodos que gostaria de melhorar
* Tipo de intervenção para cada cômodo

Clique em `Salvar`

<figure><img src="../.gitbook/assets/image (25).png" alt="" width="212"><figcaption></figcaption></figure>
