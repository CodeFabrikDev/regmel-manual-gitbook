# Confirmar projeto de melhoria

{% hint style="warning" %}
O projeto de melhoria é feito de forma externa e entregue presencialmente ao beneficiário.
{% endhint %}

Para confirmar projeto de melhoria, acesse a tela inicial&#x20;

Clique em `Projetos de Melhoria`

<figure><img src="../.gitbook/assets/image (26).png" alt="" width="213"><figcaption></figcaption></figure>

Na página exibida, selecione o item com o status 'Pendente'

Clique em `Confirmar Entrega`

<figure><img src="../.gitbook/assets/image (27).png" alt="" width="213"><figcaption></figcaption></figure>

Na tela exibida, quando o marcador verde (localização do dispositivo) estiver dentro da distância permitida do marcador azul (endereço da demanda), clique no botão `confirmar`, que estará habilitado.

<figure><img src="../.gitbook/assets/image (36).png" alt="" width="212"><figcaption></figcaption></figure>
